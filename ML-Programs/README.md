## Run
Install the required libraries first, for example:

```bash
pip install numpy pandas matplotlib scikit-learn
```

Then run a program:

```bash
python 01_find_s.py
```

Each Python file contains the runnable code and the saved console output as comments for reference. Plots are generated when the program runs; image output is not embedded in the source files.
